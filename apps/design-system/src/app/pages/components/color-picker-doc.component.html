🎨 Color Picker

Seletor de cores avançado com suporte a múltiplos formatos, paletas predefinidas e criador de gradientes. Segue o tema Muxima UI.

Exemplo Básico

Dropdown

<muxima-color-picker [(ngModel)]="selectedColor"></muxima-color-picker>

Cor selecionada: {{ selectedColor }}

Inline

<muxima-color-picker [inline]="true" [(ngModel)]="selectedColor"></muxima-color-picker>

Formatos e Paletas

HEX, RGB, HSL

<muxima-color-picker [(ngModel)]="selectedColor" [format]="format" (formatChange)="onFormatChange($event)"></muxima-color-picker>

Formato atual: {{ format }}

Paleta Customizada

<muxima-color-picker [(ngModel)]="selectedColor" [customPalettes]="customPalettes"></muxima-color-picker>

Gradiente e Opacidade

Gradiente

<muxima-color-picker [showGradient]="true" [inline]="true"></muxima-color-picker>

Com Opacidade

<muxima-color-picker [(ngModel)]="colorWithAlpha" [showAlpha]="true"></muxima-color-picker>

API

Eventos

  • colorChange: ColorFormat - Emitido quando a cor muda
  • formatChange: 'hex' | 'rgb' | 'hsl' - Emitido quando o formato muda

Interface ColorFormat

interface ColorFormat {{ '{' }}
    hex: string;
    rgb: {{ '{' }} r: number; g: number; b: number {{ '}' }};
    hsl: {{ '{' }} h: number; s: number; l: number {{ '}' }};
  {{ '}' }}

Dicas

  • Use paletas customizadas para adaptar ao seu branding.
  • O gradiente segue o tema Muxima UI: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
  • Compatível com ngModel e Reactive Forms.
  • Ideal para seletores de cor em editores, dashboards e formulários avançados.
