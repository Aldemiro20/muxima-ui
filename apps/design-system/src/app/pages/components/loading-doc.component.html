Propriedade Tipo Padrão Descrição

size 'sm' | 'md' | 'lg' | 'xl' 'md' Tamanho do loading
text string '' Texto exibido abaixo do loading

✨ Características

  • 🎨 5 variantes visuais diferentes
  • 📏 4 tamanhos (sm, md, lg, xl)
  • 🌐 Modo overlay para tela cheia
  • 💬 Texto de loading customizável
  • 🎭 Animações suaves com CSS
  • 🎨 Gradiente roxo elegante (#667eea → #764ba2)
  • 📱 Responsivo e acessível
  • ⚡ Performance otimizada

💡 Casos de Uso

  • Spinner: Carregamento de páginas, requisições API gerais
  • Dots: Indicadores discretos, chat, digitação
  • Bars: Processamento de áudio, análise de dados
  • Pulse: Sincronização, atualização em tempo real
  • Ring: Progresso circular, downloads
  • Overlay: Operações críticas, login, salvamento
  • Button: Feedback de ações, submit de formulários
