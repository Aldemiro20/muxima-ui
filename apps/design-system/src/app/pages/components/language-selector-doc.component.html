Language Selector Component

A flexible and customizable language selector component with built-in support for multiple languages, flags, and native names. Perfect for internationalization (i18n) in your Angular applications.

API Reference

Property Type Default Description
selectedLanguage string 'en' Currently selected language code (two-way binding)
languages Language[] EN, PT, ES, FR Array of available languages
position 'bottom-right' | 'bottom-left' | 'top-right' | 'top-left' 'bottom-right' Dropdown position relative to button

Events

Event Payload Description
languageChange string Emitted when language is changed, returns language code

Language Interface

interface Language {{ '{' }}
  code: string;        // ISO 639-1 code (e.g., 'en', 'pt')
  name: string;        // English name (e.g., 'English')
  flag: string;        // Flag emoji (e.g., '🇺🇸')
  nativeName?: string; // Native name (e.g., 'Português')
{{ '}' }}

Best Practices

  • ✅ Persist Selection: Save user's language preference in localStorage or cookies
  • ✅ Auto-detect: Use browser language as initial default (navigator.language)
  • ✅ Native Names: Always show language names in their native script for clarity
  • ✅ RTL Support: Handle right-to-left languages (Arabic, Hebrew) properly
  • ✅ Flag Fallback: Provide text fallback when flag emojis aren't supported
  • ✅ Loading State: Show loading indicator when switching languages
  • ✅ Error Handling: Gracefully handle missing translation files
  • ✅ SEO: Use proper hreflang tags for multilingual SEO
