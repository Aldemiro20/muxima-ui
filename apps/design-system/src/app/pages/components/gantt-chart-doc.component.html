Gantt Chart

Visualize cronogramas de projetos com tarefas, dependências e marcos

📊 Visão Geral

O componente Gantt Chart é uma ferramenta poderosa para visualização de cronogramas de projetos. Ele permite exibir tarefas ao longo do tempo, com suporte a hierarquias, dependências, progresso e marcos importantes.

Recursos Principais

📅

Timeline Interativa

Visualize tarefas em uma linha do tempo com 3 níveis de zoom (dia/semana/mês)

🔗

Dependências

Defina relações entre tarefas para mostrar o fluxo de trabalho

📊

Progresso Visual

Barras de progresso dentro das tarefas mostram percentual completo

🎯

Marcos

Destaque datas importantes com marcadores visuais

🌳

Hierarquia

Organize tarefas em estrutura pai-filho com colapso

🎨

Personalização

Cores, prioridades e responsáveis por tarefa

📋 Props (Inputs)

Prop Tipo Padrão Descrição
tasks GanttTask[] [] Array de tarefas a serem exibidas
milestones GanttMilestone[] [] Array de marcos importantes
startDate Date auto Data inicial do cronograma (calculada automaticamente se não fornecida)
endDate Date auto Data final do cronograma (calculada automaticamente se não fornecida)
zoom 'day' | 'week' | 'month' 'week' Nível de zoom da timeline
showWeekends boolean true Exibir finais de semana na timeline

🎭 Eventos (Outputs)

Evento Payload Descrição
taskClick GanttTask Emitido quando uma tarefa é clicada
taskDragEnd GanttTask Emitido quando uma tarefa é arrastada (se habilitado)
milestoneClick GanttMilestone Emitido quando um marco é clicado
zoomChange string Emitido quando o nível de zoom muda

⚡ Dicas de Performance

  • Virtualize tarefas: Para muitas tarefas (>100), considere implementar scroll virtual
  • Agrupe por hierarquia: Use a estrutura pai-filho para organizar muitas tarefas
  • Otimize zoom: Comece com zoom "week" ou "month" para grandes períodos
  • Lazy load: Carregue dados sob demanda conforme o usuário navega

♿ Acessibilidade
