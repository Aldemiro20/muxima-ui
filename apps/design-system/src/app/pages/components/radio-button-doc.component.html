✨ Boas Práticas

Use radio buttons quando houver 2-7 opções. Para mais opções, considere um select/dropdown.
Sempre forneça labels descritivos para melhor compreensão.
Use descrições quando as opções precisarem de esclarecimento adicional.
Agrupe radio buttons relacionados com o mesmo atributo 'name'.
Considere pré-selecionar uma opção padrão quando apropriado.
Mantenha a ordem lógica das opções (alfabética, numérica, por popularidade).

♿ Acessibilidade

🎯 Recursos de Acessibilidade

  • Suporte completo para navegação por teclado (Tab, Space, Enter)
  • Atributos ARIA apropriados (role="radio", aria-checked, aria-disabled)
  • Indicador visual de foco para usuários de teclado
  • Labels associados corretamente para leitores de tela
  • Suporte para indicador de campo obrigatório
  • Estados desabilitado e selecionado claramente diferenciados
