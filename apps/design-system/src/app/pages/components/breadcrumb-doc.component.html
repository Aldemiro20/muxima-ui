API

Interface BreadcrumbItem

Propriedade Tipo Obrigatório Descrição
label string Sim Texto exibido no item
url string Não URL para navegação (omitir no último item)
icon string Não Ícone/emoji exibido antes do label

Classes CSS Disponíveis

Classe Descrição
.breadcrumb Container principal do breadcrumb
.breadcrumb-list Lista ordenada de items
.breadcrumb-item Item individual do breadcrumb
.breadcrumb-link Link clicável
.breadcrumb-current Item atual (último)

Boas Práticas

  • Sempre comece com a página inicial ou raiz
  • O último item deve ser não-clicável (página atual)
  • Use ícones consistentes em toda a aplicação
  • Mantenha labels curtos e descritivos
  • Considere colapsar breadcrumbs longos em mobile
  • Use aria-label para acessibilidade
  • Evite breadcrumbs com apenas 1 item
  • Não duplique o título da página no breadcrumb
