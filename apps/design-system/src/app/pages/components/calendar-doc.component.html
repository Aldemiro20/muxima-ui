Código HTML

<muxima-calendar
  [events]="events"
  [view]="'month'"
  [locale]="'pt-BR'"
  (eventClicked)="onEventClick($event)"
  (dateClicked)="onDateClick($event)">
</muxima-calendar>

📋 Props

Prop Tipo Descrição
events CalendarEvent[] Array de eventos do calendário
view 'month' | 'week' | 'day' | 'agenda' Modo de visualização
locale string Localização (pt-BR, en-US, etc)
weekStartsOn 'sunday' | 'monday' Dia de início da semana
