📚 Referência da API

Inputs

Propriedade Tipo Padrão Descrição
placeholder string 'Escreva algo incrível...' Texto placeholder
readOnly boolean false Modo somente leitura
height string '400px' Altura do editor
theme 'snow' | 'bubble' 'snow' Tema visual
showToolbar boolean true Exibir toolbar
customToolbar boolean false Usar toolbar customizada

Outputs

Evento Tipo Descrição
contentChanged EventEmitter<any> Emitido quando o conteúdo muda
selectionChanged EventEmitter<any> Emitido quando a seleção muda
editorCreated EventEmitter<any> Emitido quando o editor é criado

Métodos

Método Retorno Descrição
getWordCount() number Retorna contagem de palavras
getCharCount() number Retorna contagem de caracteres
clear() void Limpa todo o conteúdo
