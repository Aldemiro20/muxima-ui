⌨️ Command Palette

Paleta de comandos com busca fuzzy e atalhos de teclado

📖 Visão Geral

O Command Palette é uma paleta de comandos estilo Spotlight/VSCode, que permite acesso rápido a funcionalidades através de busca fuzzy e atalhos de teclado. Ideal para melhorar a produtividade e navegação em aplicações complexas.

⚡

Atalho Global

Abra com Ctrl+K de qualquer lugar

🔍

Busca Fuzzy

Encontre comandos rapidamente

⌨️

Navegação

Use setas e Enter para navegar

🎯

Categorizado

Comandos organizados por categoria

Ctrl + K para abrir a paleta

🚀 Exemplo de Uso

TypeScript (Component)

import {{'{'}}{{'{'}} CommandPaletteComponent, CommandItem } from '@muxima-ui/command-palette';

commands: CommandItem[] = [
  {{'{'}}{{'{'}}
    id: 'nav-home',
    label: 'Ir para Home',
    description: 'Navegar para página inicial',
    icon: '🏠',
    category: 'Navegação',
    shortcut: 'Ctrl+H',
    action: () => this.navigateTo('/'),
    keywords: ['home', 'início', 'principal']
  },
  {{'{'}}{{'{'}}
    id: 'action-new-project',
    label: 'Novo Projeto',
    description: 'Criar um novo projeto',
    icon: '➕',
    category: 'Ações',
    shortcut: 'Ctrl+N',
    action: () => this.createNew(),
    keywords: ['new', 'novo', 'criar']
  }
];

onCommandExecuted(command: CommandItem): void {{'{'}}{{'{'}}
  console.log('Comando executado:', command);
}

HTML (Template)

<muxima-command-palette
  [commands]="commands"
  placeholder="Digite um comando..."
  [maxResults]="8"
  (commandExecuted)="onCommandExecuted($event)">
</muxima-command-palette>

📚 API Reference

Inputs

Propriedade Tipo Padrão Descrição
commands CommandItem[] [] Array de comandos disponíveis
placeholder string 'Digite um comando...' Placeholder do input de busca
shortcut string 'Ctrl+K' Atalho para abrir a paleta
maxResults number 8 Número máximo de resultados

Outputs

Evento Payload Descrição
commandExecuted CommandItem Emitido ao executar um comando
closed void Emitido ao fechar a paleta

Métodos Públicos

Método Parâmetros Descrição
open() void Abre a paleta programaticamente
close() void Fecha a paleta
toggle() void Alterna entre aberto/fechado

Interface CommandItem

interface CommandItem {{'{'}}{{'{'}}
  id: string;
  label: string;
  description?: string;
  icon?: string;
  shortcut?: string;
  category?: string;
  action: () => void;
  keywords?: string[];
}

🔍 Busca Fuzzy

O Command Palette utiliza busca fuzzy para encontrar comandos mesmo com digitação incompleta ou fora de ordem. Exemplos:

nvhm → Navegar para Home
nprj → Novo Projeto
doc → Documentação
💡 Dica: A busca também procura nas palavras-chave (keywords) definidas em cada comando, ampliando as possibilidades de correspondência.
