Inputs

Propriedade Tipo Padrão Descrição

currentStep number 0 Índice do passo atual (zero-based)

clickable boolean true Permite navegação por clique nos passos

Outputs

Evento Tipo Descrição

Step Interface

interface Step {{ '{' }}
  label: string;          // Título do passo
  description?: string;   // Descrição opcional
  icon?: string;         // Ícone emoji ou classe
  completed?: boolean;    // Se o passo foi completado
  disabled?: boolean;     // Se o passo está desabilitado
{{ '}' }}

💡 Casos de Uso

Formulários Multi-Etapa: Divida formulários longos em passos menores para melhor UX. Use validação em cada passo antes de permitir o avanço.
Processo de Checkout: Guie usuários através de carrinho → endereço → pagamento → confirmação com feedback visual do progresso.
Onboarding: Crie fluxos de boas-vindas para novos usuários com múltiplas etapas de configuração e personalização.
Wizards: Implemente assistentes de configuração complexos com navegação linear e validação de dados em cada etapa.
