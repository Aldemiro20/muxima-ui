📋 API

Propriedade Tipo Padrão Descrição
items CarouselItem[] [] Array de itens do carrossel com image, title, description e link opcionais
autoPlay boolean true Ativa a reprodução automática dos slides
interval number 5000 Intervalo em milissegundos entre slides (quando autoPlay está ativo)
showArrows boolean true Exibe as setas de navegação anterior/próximo
showDots boolean true Exibe os indicadores de posição (dots) na parte inferior
height string '400px' Altura do carrossel (aceita qualquer valor CSS válido)
animationType 'slide' | 'fade' 'slide' Tipo de transição entre slides

Dicas de Uso

Performance

O carousel pausa automaticamente quando o mouse está sobre ele, economizando recursos.

Imagens

Use imagens com proporção 16:9 para melhor resultado visual. Recomendado: 1920x1080px.

Acessibilidade

Todos os botões possuem atributos adequados e são navegáveis via teclado.

Responsivo

O componente se adapta automaticamente a diferentes tamanhos de tela.
