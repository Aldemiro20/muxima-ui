Chart Component

A flexible and lightweight charting component that supports multiple chart types with smooth animations. Built using native Canvas 2D API without external dependencies.

Features

📊

4 Chart Types

Line, Bar, Pie, and Donut charts

🎨

8 Gradient Colors

Beautiful default color palette

⚡

Smooth Animations

60fps using requestAnimationFrame

🪶

Lightweight

No external chart libraries

Size Variants

Three size options to fit different layouts and use cases.

API Reference

Property Type Default Description
data ChartData - Chart data with labels and datasets
type 'line' | 'bar' | 'pie' | 'donut' 'line' Type of chart to render
title string '' Chart title displayed above
size 'sm' | 'md' | 'lg' 'md' Chart size (200px, 300px, 400px)
animated boolean true Enable smooth animations

Use Cases

📈 Analytics Dashboard

Display website analytics with line charts for visitors, page views, and engagement metrics over time.

💼 Sales Reports

Use bar charts to compare sales performance across products, regions, or time periods.

📊 Market Research

Visualize survey results and market share data with pie and donut charts.

💰 Financial Analysis

Track revenue, expenses, and profit trends with multi-dataset line and bar charts.

🎯 KPI Monitoring

Monitor key performance indicators with real-time updating charts and smooth animations.

📱 Mobile Dashboards

Use small size variant for compact mobile-friendly dashboard widgets.
