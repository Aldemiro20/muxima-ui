API Reference

Inputs

Property Type Default Description
columns TableColumn[] [] Column definitions
data any[] [] Data array
config TableConfig Default Table configuration
loading boolean false Show loading overlay
emptyMessage string 'No data found' Empty state message

Outputs

Event Payload Description
sort SortEvent Emitted when column is sorted
filter FilterEvent Emitted when filter changes
pageChange {{ '{page, pageSize}' }} Emitted when page changes
rowSelect any Emitted when row is selected
rowUnselect any Emitted when row is unselected
selectionChange any[] Emitted when selection changes
export any[] Emitted when export is triggered

Usage Tips

💡 Nested Data: Access nested properties using dot notation: user.profile.name
💡 Multi-Select: Hold Ctrl (Cmd on Mac) and click to select multiple rows
💡 Column Resizing: Drag the border between column headers to resize
💡 Sorting States: Click once for ascending, twice for descending, third time to remove sort
💡 Performance: For large datasets (1000+ rows), consider server-side pagination
