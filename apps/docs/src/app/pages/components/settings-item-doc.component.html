💡 Boas Práticas

✅
Labels claras e concisas

Use títulos curtos que descrevam claramente a configuração. Máximo 2-4 palavras.

✅
Descrições úteis

Adicione contexto sobre o que a configuração afeta ou como será usada.

✅
Use variantes apropriadas

Toggle para on/off, action para botões, default para inputs/selects.

✅
Agrupe por contexto

Use .settings-group para agrupar items relacionados com espaçamento consistente.

✅
Mantenha consistência

Use os mesmos estilos de input/button em toda a página de settings.
