📋 API Reference

Propriedades disponíveis para customização do componente

Propriedade Tipo Padrão Descrição
title string '' Título principal exibido no header do accordion
subtitle string '' Texto secundário opcional abaixo do título
expanded boolean false Define se o accordion inicia aberto ou fechado
disabled boolean false Desabilita a interação do usuário
icon string '' Ícone a ser exibido ao lado do título
iconUrl string '' URL de imagem para ícone customizado
children any[] [] Array de sub-itens para estrutura aninhada
isChild boolean false Indica se é um accordion filho (interno)
childLevel number 0 Nível de profundidade na hierarquia

💡 Melhores Práticas

✅ Recomendado

  • Títulos claros: Use títulos descritivos e concisos (máx. 50 caracteres)
  • Agrupamento lógico: Organize conteúdo relacionado sob o mesmo accordion
  • Estado inicial: Em FAQs, deixe apenas 1 item aberto por vez
  • Subtítulos informativos: Use para adicionar contexto sem poluir o título
  • Hierarquia moderada: Limite aninhamento a 2-3 níveis

❌ Evite

  • Aninhamento profundo: Mais de 3 níveis dificulta navegação
  • Conteúdo crítico oculto: Informações essenciais devem estar visíveis
  • Navegação principal: Não use accordion para menu principal do site
  • Títulos longos: Evite textos que quebrem em múltiplas linhas
  • Muitos itens abertos: Ter muitos accordions expandidos gera confusão
