API

Timeline Component

Propriedade Tipo Padrão Descrição
items TimelineItem[] [] Array de itens da timeline
mode 'vertical' | 'horizontal' 'vertical' Orientação da timeline
align 'left' | 'alternate' | 'right' 'left' Alinhamento do conteúdo
showConnector boolean true Exibir linha conectora
animated boolean true Ativar animações

TimelineItem Interface

Propriedade Tipo Obrigatório Descrição
title string Sim Título do evento
description string Não Descrição detalhada
date string Não Data do evento
time string Não Horário do evento
icon string Não Emoji ou ícone customizado
status 'completed' | 'current' | 'upcoming' | 'error' Não Estado do evento
color 'blue' | 'purple' | 'green' | 'orange' | 'red' | 'gray' Não Cor predefinida do marcador
customColor string Não Cor customizada (hex, rgb)
