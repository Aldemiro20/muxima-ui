📚 API Reference

Propriedade Tipo Padrão Descrição
name string - Nome para gerar iniciais automaticamente
src string - URL da imagem do avatar
size 'xs' | 'sm' | 'md' | 'lg' | 'xl' | '2xl' 'md' Tamanho do avatar
shape 'circle' | 'square' | 'rounded' 'circle' Forma do avatar
status 'online' | 'offline' | 'away' | 'busy' | 'none' 'none' Indicador de status do usuário
badge string | number - Número ou texto para o badge de notificação
bgColor string auto Cor de fundo personalizada (hex, rgb, etc)
clickable boolean false Torna o avatar clicável com cursor pointer
tooltip string - Texto do tooltip ao passar o mouse
avatarClick EventEmitter<MouseEvent> - Evento disparado ao clicar no avatar
