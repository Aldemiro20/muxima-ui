📋 API

Propriedade Tipo Padrão Descrição
placeholder string 'Search...' Texto placeholder do input
size 'sm' | 'md' | 'lg' 'md' Tamanho do componente
variant 'default' | 'outlined' | 'filled' 'default' Variante visual do componente
disabled boolean false Desabilita o componente
clearable boolean true Mostra botão de limpar quando há texto
loading boolean false Exibe spinner de carregamento
debounceTime number 300 Tempo de debounce em milissegundos
ngModel string '' Valor do input (two-way binding)

Eventos

Evento Tipo Descrição
(search) EventEmitter<string> Emitido após o debounce quando o usuário digita
(clear) EventEmitter<void> Emitido quando o botão de limpar é clicado
(focus) EventEmitter<void> Emitido quando o input recebe foco
(blur) EventEmitter<void> Emitido quando o input perde foco

💡 Melhores Práticas

  • ✅ Use debounce para evitar muitas chamadas de API durante a digitação
  • ✅ Mostre o estado de loading durante pesquisas assíncronas
  • ✅ Use placeholders descritivos que indiquem o que pode ser pesquisado
  • ✅ Mantenha o botão de limpar visível para melhor UX
  • ✅ Use o tamanho 'sm' em toolbars e 'md' em páginas principais
  • ⚠️ Evite debounce muito curto (< 200ms) para não sobrecarregar o servidor
  • ⚠️ Considere usar a variante 'filled' em fundos escuros
