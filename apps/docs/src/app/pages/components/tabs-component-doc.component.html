📚 API Reference

Inputs

Propriedade Tipo Padrão Descrição
tabs TabItem[] [] Array de tabs a serem exibidas
activeTab string '' ID da tab atualmente ativa
variant 'default' | 'underline' | 'pills' | 'bordered' 'underline' Estilo visual das tabs

Outputs

Evento Tipo Descrição
activeTabChange string Emitido quando a tab ativa muda (two-way binding)
tabChange TabItem Emitido quando uma tab é clicada, retorna o objeto completo

Interface TabItem

interface TabItem {{'{' }}
  id: string;              // Identificador único da tab
  label: string;           // Texto exibido na tab
  icon?: string;           // Path SVG do ícone (opcional)
  icon2?: string;          // Segundo path SVG (opcional, para ícones complexos)
  disabled?: boolean;      // Se true, a tab não pode ser clicada
{{'}'}}

💡 Boas Práticas

✅
Use 3-7 tabs

Número ideal para não sobrecarregar a interface. Para mais opções, considere outro padrão de navegação.

✅
Labels claras e concisas

Use palavras simples que descrevam claramente o conteúdo de cada seção.

✅
Ícones quando apropriado

Ícones ajudam na identificação rápida, mas não são necessários em todos os casos.

✅
Escolha a variante certa

Underline para settings, Pills para filters, Bordered para cards/containers.
