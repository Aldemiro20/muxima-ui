📚 API

Inputs

Propriedade Tipo Padrão Descrição
items CartItem[] [] Lista de itens no carrinho
config CartConfig Ver abaixo Configurações do carrinho
disabled boolean false Desabilita todas as interações
emptyMessage string "Seu carrinho está vazio" Mensagem quando vazio
showCheckout boolean true Mostra botão de checkout
size 'small' | 'medium' | 'large' 'medium' Tamanho do componente

Outputs

Evento Tipo Descrição
checkout EventEmitter<CartItem[]> Emitido ao clicar em "Finalizar Compra"
itemRemoved EventEmitter<CartItem> Emitido quando um item é removido
itemQuantityChanged EventEmitter<{item, quantity}> Emitido quando quantidade muda
clearCart EventEmitter<void> Emitido ao limpar carrinho

CartItem Interface

interface CartItem {
  id: string;
  name: string;
  price: number;
  quantity: number;
  image?: string;
  description?: string;
  maxQuantity?: number;
}

CartConfig Interface

interface CartConfig {
  currency?: string;           // Padrão: 'R$'
  showImages?: boolean;        // Padrão: true
  allowQuantityEdit?: boolean; // Padrão: true
  showSubtotal?: boolean;      // Padrão: true
  taxRate?: number;            // Padrão: 0 (0.15 = 15%)
  shippingCost?: number;       // Padrão: 0
}
