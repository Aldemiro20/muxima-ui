📚 API

Inputs

Propriedade Tipo Padrão Descrição
content string '' Conteúdo a ser copiado
label string 'Copiar' Texto do botão
successMessage string 'Copiado!' Mensagem de sucesso
errorMessage string 'Erro ao copiar' Mensagem de erro
disabled boolean false Desabilita o botão
size 'small' | 'medium' | 'large' 'medium' Tamanho do botão
variant 'button' | 'icon' | 'inline' 'button' Estilo do botão
showFeedback boolean true Mostra feedback visual
feedbackDuration number 2000 Duração do feedback (ms)
showTooltip boolean true Mostra tooltip ao hover

Outputs

Evento Tipo Descrição
copied EventEmitter<string> Emitido quando o conteúdo é copiado com sucesso
error EventEmitter<Error> Emitido quando ocorre um erro ao copiar
