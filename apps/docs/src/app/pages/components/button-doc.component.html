Melhores Práticas

Faça

  • Use Primary para a ação principal da página
  • Use Secondary para ações secundárias e alternativas
  • Use Danger apenas para ações destrutivas (deletar, remover)
  • Mantenha textos de botões curtos e objetivos (2-4 palavras)
  • Use ícones para reforçar o significado da ação
  • Agrupe botões relacionados próximos uns dos outros
  • Mantenha consistência de tamanhos em uma mesma seção
  • Use [wFull]="true" em dispositivos móveis

Evite

  • Usar múltiplos botões Primary na mesma tela
  • Textos muito longos que quebram em múltiplas linhas
  • Botões Danger sem confirmação para ações irreversíveis
  • Misturar muitos tamanhos diferentes na mesma seção
  • Usar ícones ambíguos ou confusos
  • Desabilitar botões sem explicação do motivo
  • Botões muito pequenos em dispositivos touch (mínimo 44x44px)
  • Cores personalizadas que quebram a hierarquia visual

Acessibilidade

  • Contraste: Todos os botões atendem aos padrões WCAG AA
  • Teclado: Totalmente navegáveis via Tab e Enter/Space
  • Focus: Estados de foco visíveis para navegação por teclado
  • ARIA: Atributos semânticos adequados para leitores de tela
  • Touch: Área mínima de 44x44px para dispositivos touch
  • Estados: Estados desabilitados claramente indicados visualmente
