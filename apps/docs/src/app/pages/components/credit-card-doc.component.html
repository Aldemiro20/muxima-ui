📋 API

Inputs

Prop Tipo Padrão Descrição
showCard boolean true Exibe o cartão visual 3D
disabled boolean false Desabilita o formulário
labels object {{ '{' }}...{{ '}' }} Labels personalizados dos campos

Outputs

Evento Tipo Descrição
cardTypeChange EventEmitter<string> Emitido quando a bandeira é detectada
validationChange EventEmitter<object> Emitido quando um campo é validado

Interface CreditCardData

Propriedade Tipo Descrição
number string Número do cartão (13-19 dígitos)
name string Nome no cartão
expiry string Data de validade (MM/AA)
cvv string Código de segurança (3-4 dígitos)
type string Bandeira detectada (visa, mastercard, etc)
