API Reference

Properties

Property Type Default Description
variant 'default' | 'centered' | 'split' | 'minimal' | 'gradient' | 'image-bg' 'default' Variante visual do hero
size 'sm' | 'md' | 'lg' | 'xl' 'lg' Tamanho do hero (afeta principalmente o título)
alignment 'left' | 'center' | 'right' 'left' Alinhamento do conteúdo
announcement string '' Texto do badge de anúncio (suporta HTML)
announcementBadge string '' Label do badge destacado no anúncio
highlightText string '' Texto destacado com gradient no título
subtitle string '' Subtítulo descritivo
features string[] [] Lista de features com checkmark
showCta boolean true Mostrar ou ocultar área de CTA
showVisual boolean true Mostrar ou ocultar área visual (variants split/default)
backgroundImage string '' URL da imagem de fundo (variant image-bg)

Content Projection

Selector Description
[title] Conteúdo do título principal
[cta] Botões de call-to-action
[visual] Área visual/mockup (variants split/default)

Events

Event Type Description
ctaClick EventEmitter<void> Emitido quando CTA é clicado

Best Practices

✅
Use variant adequada ao contexto

Default/Split para landing pages, Centered para produtos, Minimal para documentação

✅
Mantenha títulos concisos

Títulos curtos e impactantes (3-7 palavras) convertem melhor

✅
Use highlightText estrategicamente

Destaque a palavra-chave principal ou valor único da sua oferta

✅
Limite features a 3-4 itens

Lista muito longa dilui a mensagem principal

⚠️
Evite imagens pesadas no image-bg

Otimize imagens para web (WebP, compressão) para melhor performance

⚠️
Teste em mobile

Heroes são responsivos mas teste sempre em diferentes tamanhos de tela

✅
Use CTAs com contraste

Primeiro botão sempre primary, segundo outline/ghost para hierarquia clara

✅
Adicione visual impactante

Mockups, screenshots ou ilustrações aumentam credibilidade e engajamento

✅
Use stats inline para e-commerce

Estatísticas de clientes, avaliações e produtos reforçam confiança e credibilidade

✅
Floating elements criam dinamismo

Cards de produtos com animação floating chamam atenção e melhoram engajamento visual

Use Cases

🚀 SaaS Landing Pages

Use default ou split com mockup do dashboard e features principais.

🛍️ E-commerce

Use split com stats inline, product cards flutuantes e CTAs de compra. Perfeito para mostrar produtos em destaque.

📱 App Landing

Use centered com screenshots do app e links de download.

📚 Documentação

Use minimal para páginas de getting started e overview.

🎉 Promoções

Use gradient com anúncio destacado e countdown timer.

🏢 Corporate

Use default com vídeo ou ilustração profissional.

🖼️ Portfolio/Creative

Use image-bg com imagem de alta qualidade e overlay para criar impacto visual forte.
