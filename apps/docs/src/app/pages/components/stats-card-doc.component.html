📋 API

Propriedade Tipo Padrão Descrição
label string '' Rótulo descritivo da métrica
value string | number '' Valor principal da métrica
icon string '' Emoji ou ícone para identificação visual
iconSvg string '' Código SVG customizado para o ícone
trend number 0 Percentual de variação (positivo ou negativo)
trendLabel string '' Descrição do período de comparação
color 'primary' | 'blue' | 'green' | 'orange' | 'red' | 'purple' 'primary' Cor do tema do card
variant 'default' | 'compact' | 'minimal' 'default' Variante visual do card
size 'sm' | 'md' | 'lg' 'md' Tamanho do card
loading boolean false Exibe estado de carregamento
sparklineData number[] [] Array de valores para o gráfico sparkline

💡 Casos de Uso

📊 Dashboards Analíticos

Exibir KPIs principais como receita, usuários ativos, conversões e métricas de performance.

💼 Painéis Administrativos

Monitorar estatísticas de vendas, pedidos, estoque e dados operacionais em tempo real.

📈 Relatórios Executivos

Apresentar métricas de negócio com tendências e comparações de períodos.

🎯 Performance Tracking

Acompanhar metas e objetivos com indicadores visuais de progresso e variação.
