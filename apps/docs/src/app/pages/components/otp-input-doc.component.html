📋 API

Inputs

Prop Tipo Padrão Descrição
length number 6 Quantidade de dígitos do código
type 'number' | 'text' 'number' Tipo de caracteres aceitos
placeholder string '' Placeholder para cada campo
disabled boolean false Desabilita o input
secure boolean false Oculta os dígitos (password)
autoFocus boolean true Foco automático no primeiro campo
size 'small' | 'medium' | 'large' 'medium' Tamanho dos campos

Outputs

Evento Tipo Descrição
otpComplete EventEmitter<string> Emitido quando todos os campos são preenchidos
otpChange EventEmitter<string> Emitido a cada mudança no código

Métodos

Método Descrição
clear() Limpa todos os campos e retorna o foco ao primeiro
