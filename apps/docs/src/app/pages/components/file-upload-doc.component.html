⚙️ API

Inputs

Propriedade Tipo Padrão Descrição
accept string '*/*' Tipos de arquivo aceitos (ex: 'image/*', '.pdf,.doc')
maxSize number 10 Tamanho máximo por arquivo em MB
multiple boolean true Permite seleção de múltiplos arquivos
disabled boolean false Desabilita o componente
placeholder string 'Clique ou arraste arquivos aqui' Texto exibido na área de upload

Outputs

Evento Tipo Descrição
filesChange File[] Emitido quando arquivos são adicionados
fileRemoved File Emitido quando um arquivo é removido
