⚙️ API

Inputs

Propriedade Tipo Padrão Descrição
logo string 'Muxima' Texto ou nome da marca exibido no logo
logoRoute string '/' Rota para o link do logo
menuItems NavItem[] [] Array de itens do menu de navegação
transparent boolean false Se true, navbar começa transparente
fixed boolean true Se true, navbar fica fixo no topo da página

NavItem Interface

interface NavItem {{ '{' }}
  label: string;        // Texto do item
  route?: string;       // Rota do Angular Router
  href?: string;        // Link externo (abre em nova aba)
  icon?: string;        // Ícone (emoji ou classe)
  children?: NavItem[]; // Sub-itens para dropdown
{{ '}' }}

💡 Dicas de Uso

Navbar Fixo vs. Estático: Use fixed="true" quando quiser que o navbar permaneça visível durante o scroll. Use fixed="false" para comportamento de scroll normal.
Transparente em Hero Sections: Combine transparent="true" com fixed="true" para um efeito elegante em landing pages com imagens de fundo.
Ícones nos Menus: Use emojis ou classes de ícones (FontAwesome, Material Icons) na propriedade icon para adicionar contexto visual aos itens do menu.
