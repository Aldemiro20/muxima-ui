API

Propriedades

Propriedade Tipo Padrão Descrição
currentPage number 1 Página atual selecionada
totalPages number - Número total de páginas
itemsPerPage number 10 Quantidade de itens por página
totalItems number - Total de itens no conjunto de dados

Métodos

Método Parâmetros Descrição
goToPage page: number Navega para uma página específica
previousPage - Navega para a página anterior
nextPage - Navega para a próxima página
getVisiblePages - Retorna array de páginas visíveis com '...'

Dicas de Uso

💡
Escolha a variante certa: Use compact para espaços limitados, basic para listagens completas, e minimal para interfaces simples.
⚡
Performance: Para grandes conjuntos de dados (1000+ páginas), use o método getVisiblePages() para limitar botões renderizados.
📱
Mobile: Em telas pequenas, considere usar a variante compact ou minimal para melhor experiência.
♿
Acessibilidade: Sempre desabilite botões quando não aplicável e use aria-labels descritivos para leitores de tela.
🎯
Estado de Loading: Desabilite a paginação durante carregamento de dados para evitar múltiplas requisições simultâneas.
🔗
URL Sync: Sincronize a página com query params da URL para permitir compartilhamento e bookmarking.
