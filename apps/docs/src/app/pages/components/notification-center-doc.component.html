📚 Referência da API

Inputs

Propriedade Tipo Padrão Descrição
notifications Notification[] [] Array de notificações
position NotificationPosition 'top-right' Posição dos toasts
maxToasts number 3 Máximo de toasts visíveis
defaultDuration number 5000 Duração padrão dos toasts (ms)
showBadge boolean true Mostrar badge de contagem
groupByCategory boolean false Agrupar por categoria

Outputs

Evento Tipo Descrição
notificationRead string ID da notificação marcada como lida
notificationDismissed string ID da notificação dispensada
notificationAction Notification Notificação com ação executada
allRead void Todas marcadas como lidas
allCleared void Todas removidas

Interfaces

interface Notification {{'{'}}
  id: string;
  type: NotificationType;
  title: string;
  message: string;
  timestamp: Date;
  read: boolean;
  category?: string;
  actionLabel?: string;
  actionCallback?: () => void;
  autoClose?: boolean;
  duration?: number;
{{'}'}}

type NotificationType = 'success' | 'info' | 'warning' | 'error';

type NotificationPosition = 
  | 'top-right' 
  | 'top-left' 
  | 'bottom-right' 
  | 'bottom-left' 
  | 'top-center' 
  | 'bottom-center';
