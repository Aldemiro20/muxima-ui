API

Propriedade Tipo Padrão Descrição
mode 'single' | 'range' 'single' Modo de seleção: data única ou período
value Date | DateRange undefined Valor selecionado (data única ou período)
placeholder string 'Selecione uma data' Texto exibido quando nenhuma data está selecionada
minDate Date undefined Data mínima permitida para seleção
maxDate Date undefined Data máxima permitida para seleção
format string 'dd/MM/yyyy' Formato de exibição da data

Eventos (@Output)

Evento Tipo Descrição
valueChange EventEmitter<Date | DateRange> Emitido quando o valor é alterado (permite two-way binding)
dateSelect EventEmitter<Date> Emitido sempre que uma data é clicada no calendário

Recursos

Navegação Intuitiva

Navegue pelos meses com setas e selecione datas com um clique.

Validação Automática

Datas fora do intervalo permitido são desabilitadas automaticamente.

Hover Preview

Visualize o período selecionado ao passar o mouse no modo range.

Atalhos Rápidos

Botões "Hoje" e "Limpar" para seleção rápida.
