📋 API

Inputs

Prop Tipo Padrão Descrição
maxStars number 5 Quantidade máxima de estrelas
allowHalf boolean true Permite meias-estrelas
readonly boolean false Modo somente leitura
disabled boolean false Desabilita a interação
size 'small' | 'medium' | 'large' 'medium' Tamanho das estrelas
color string '#fbbf24' Cor das estrelas preenchidas
emptyColor string '#d1d5db' Cor das estrelas vazias
showCount boolean true Exibe o contador numérico
showLabel boolean false Exibe label descritivo
customLabels string[] ['Péssimo', ...] Labels personalizados

Outputs

Evento Tipo Descrição
ratingChange EventEmitter<number> Emitido quando a avaliação muda
ratingHover EventEmitter<number> Emitido ao passar o mouse sobre as estrelas
