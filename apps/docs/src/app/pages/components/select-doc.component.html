Propriedades do Componente

Propriedade Tipo Padrão Descrição
options SelectOption[] [] Array de opções do select
placeholder string 'Selecione uma opção' Texto quando nada está selecionado
label string - Label acima do select
helperText string - Texto de ajuda abaixo do select
variant 'default' | 'outlined' | 'filled' | 'gradient' 'default' Estilo visual do select
size 'sm' | 'md' | 'lg' 'md' Tamanho do select
searchable boolean false Habilita busca nas opções
multiple boolean false Permite seleção múltipla
clearable boolean false Mostra botão para limpar seleção
prefixIcon string - Ícone antes do texto
disabled boolean false Desabilita o select
readonly boolean false Select somente leitura
hasError boolean false Exibe estado de erro
errorMessage string - Mensagem de erro
