💡 Melhores Práticas

✅ Recomendado

  • Tipo apropriado: Use o tipo semântico correto (info, success, warning, error)
  • Mensagens claras: Seja específico e objetivo nas mensagens
  • Posicionamento: Coloque alertas próximos ao contexto relevante
  • Dismissível quando apropriado: Permita fechar alertas não-críticos
  • Títulos descritivos: Use títulos para mensagens mais longas

❌ Evite

  • Múltiplos alertas: Evite mostrar muitos alertas ao mesmo tempo
  • Mensagens genéricas: "Erro" sozinho não ajuda o usuário
  • Alertas para tudo: Use para feedback importante, não trivial
  • Texto muito longo: Mantenha mensagens concisas e diretas
  • Alertas permanentes: Erros críticos devem ter ação clara
