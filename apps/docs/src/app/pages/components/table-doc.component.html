API

Propriedades do Componente

Propriedade Tipo Padrão Descrição
columns TableColumn[] [] Configuração das colunas
data any[] [] Dados da tabela
loading boolean false Exibe overlay de loading
striped boolean false Linhas zebradas
hoverable boolean true Efeito hover nas linhas
bordered boolean false Bordas entre colunas
compact boolean false Espaçamento reduzido
pagination TablePagination - Configuração da paginação
showPagination boolean true Exibe paginação
pageSizeOptions number[] [5, 10, 25, 50, 100] Opções de itens por página

Eventos

Evento Tipo Descrição
pageChange PaginationEvent Emitido quando a página ou tamanho muda
sortChange SortEvent Emitido quando uma coluna é ordenada

Interface TableColumn

Propriedade Tipo Obrigatório Descrição
key string Sim Chave do dado
label string Sim Texto do header
sortable boolean Não Coluna ordenável
width string Não Largura da coluna
align 'left' | 'center' | 'right' Não Alinhamento do conteúdo

Interface TablePagination

Propriedade Tipo Descrição
currentPage number Página atual (começa em 0)
totalElements number Total de registros
itemsPerPage number Itens por página
