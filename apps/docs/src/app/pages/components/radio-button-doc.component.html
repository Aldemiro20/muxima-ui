Radio Button

Componente profissional de seleção única com múltiplas variantes visuais, suporte a ícones, badges e integração completa com formulários Angular.

Instalação

Radio Button Básico

Radio buttons permitem que o usuário selecione apenas uma opção de um grupo. Todos os radio buttons do mesmo grupo devem compartilhar o mesmo atributo name.

Selecionado: {{ selectedBasic }}

Tamanhos

Disponível em 5 tamanhos diferentes para se adaptar a qualquer contexto de interface.

Cores

7 cores temáticas para se adequar perfeitamente ao design system da sua aplicação.

Variant: Card

Cards interativos ideais para seleção de planos, produtos ou opções ricas com ícones, preços e badges.

Variant: Button

Estilo de botão segmentado perfeito para alternar entre 2-4 opções em uma interface compacta.

Variant: Tile

Tiles compactos e elegantes, ideais para seleção visual de categorias, ícones ou opções.

Propriedades

Nome Tipo Padrão Descrição
value any '' Valor do radio button
name string '' Nome do grupo (obrigatório para agrupar radio buttons)
label string '' Texto principal
subtitle string '' Subtítulo adicional
description string '' Texto descritivo
size 'xs' | 'sm' | 'md' | 'lg' | 'xl' 'md' Tamanho do componente
color 'primary' | 'success' | 'warning' | 'danger' | 'info' | 'purple' | 'pink' 'primary' Cor temática
variant 'default' | 'card' | 'button' | 'tile' | 'minimal' 'default' Estilo visual
icon string '' Emoji ou ícone
badge string '' Badge de destaque
price string '' Preço (para cards)
disabled boolean false Desabilita interação
error boolean false Estado de erro
helperText string '' Texto de ajuda/erro
showCheckIcon boolean false Check ao invés de dot
glow boolean false Efeito de brilho
