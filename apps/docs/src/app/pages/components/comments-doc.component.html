📚 API

Inputs

Propriedade Tipo Padrão Descrição
comments Comment[] [] Lista de comentários
currentUser {name, avatar?} null Usuário logado atual
allowReplies boolean true Permite respostas
allowEdit boolean true Permite edição
allowDelete boolean true Permite exclusão
allowLikes boolean true Permite curtidas
maxDepth number 3 Profundidade máxima de replies
sortBy 'newest' | 'oldest' | 'likes' 'newest' Ordenação dos comentários

Outputs

Evento Tipo Descrição
commentAdded EventEmitter<Comment> Novo comentário adicionado
commentEdited EventEmitter<Comment> Comentário editado
commentDeleted EventEmitter<Comment> Comentário removido
commentLiked EventEmitter<Comment> Comentário curtido
replyAdded EventEmitter<{comment, parentId}> Resposta adicionada

Comment Interface

interface Comment {
  id: string;
  author: string;
  avatar?: string;
  content: string;
  timestamp: Date;
  likes?: number;
  replies?: Comment[];
}
