Método Retorno Descrição

isLoading() boolean Retorna o estado atual do loading
loading$ Observable<boolean> Observable do estado de loading

Boas Práticas

Adicione no Root

Coloque o componente no app.component.html para interceptar todas as requisições globalmente.

Use X-Skip-Loading

Para requisições em background (polling, notificações), use o header X-Skip-Loading para não ativar o loading.

ForceHide em Erro

Use forceHide() em erros críticos para garantir que o loading seja removido mesmo com requests pendentes.

Mensagens Contextuais

Personalize a mensagem para diferentes contextos: "Salvando...", "Processando...", "Enviando..."

Casos de Uso

Requisições HTTP

Intercepta automaticamente chamadas de API, exibindo feedback visual ao usuário.

Upload de Arquivos

Feedback durante uploads grandes com mensagem customizada "Enviando arquivo..."

Processamento de Dados

Operações longas como relatórios, exportações ou cálculos complexos.

Autenticação

Login, logout e verificações de sessão com feedback amigável.
