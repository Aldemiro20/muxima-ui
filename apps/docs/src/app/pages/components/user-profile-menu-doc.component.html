💡 Casos de Uso

🔐 Autenticação

Menu de perfil com opções de login, logout e gerenciamento de conta.

👨‍💼 Painel Admin

Acesso rápido a áreas administrativas e configurações do sistema.

💬 Social/Chat

Perfil com notificações, mensagens e status de presença online.

🛍️ E-commerce

Acesso a pedidos, lista de desejos, carrinho e preferências.

✅ Boas Práticas

  • ✅ Limite o menu a 5-8 itens principais para evitar sobrecarga visual
  • ✅ Use divideres para agrupar ações relacionadas
  • ✅ Marque ações destrutivas (logout, delete) com danger: true
  • ✅ Use badges apenas para contadores importantes (< 100)
  • ✅ Mantenha ícones consistentes (emojis ou font icons)
  • ✅ Posicione adequadamente: top para menus em rodapé, bottom para navbar
  • ✅ Implemente status online em apps de chat ou colaboração
  • ✅ Use avatars otimizados (< 50KB, dimensões adequadas)
