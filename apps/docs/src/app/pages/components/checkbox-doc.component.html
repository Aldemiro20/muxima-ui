✨ Melhores Práticas

✅

Faça

  • Use labels descritivos e claros
  • Adicione descrições para opções complexas
  • Use variant "success" para tarefas completas
  • Implemente estado indeterminado em "selecionar todos"
  • Agrupe checkboxes relacionados
  • Mantenha labels curtos e objetivos
❌

Não Faça

  • Não use checkboxes para ações imediatas (use buttons)
  • Não use checkboxes mutuamente exclusivos (use radio)
  • Não deixe checkboxes sem labels em formulários
  • Não use muitas variantes diferentes no mesmo grupo
  • Evite labels muito longos
  • Não misture checkboxes com switches

♿ Acessibilidade

🎯 Recursos Implementados

  • ARIA Attributes: aria-checked e aria-disabled
  • Navegação por Teclado: Space e Enter para toggle
  • Foco Visível: Outline em focus-visible
  • Labels Semânticos: Elemento label associado
  • Contraste: Cores com contraste adequado

⌨️ Atalhos de Teclado

  • Tab - Navegar entre checkboxes
  • Space - Toggle do checkbox focado
  • Enter - Toggle do checkbox focado
