Propriedades

Propriedade Tipo Padrão Descrição
value number 0 Valor atual do progresso
max number 100 Valor máximo do progresso
type 'linear' | 'circular' 'linear' Tipo de exibição do progresso
color 'primary' | 'success' | 'warning' | 'error' 'primary' Cor do indicador de progresso
size 'sm' | 'md' | 'lg' 'md' Tamanho do componente
showLabel boolean false Exibe a porcentagem dentro da barra
striped boolean false Ativa o padrão listrado
animated boolean false Ativa animação das listras

Dicas de Uso

💡
Escolha o tipo certo: Use linear para operações longas e circular para espaços compactos como cards.
🎨
Cores semânticas: Use success para conclusão, warning para atenção e error para falhas.
⚡
Animações: Ative animated apenas durante processamento ativo para indicar atividade contínua.
📱
Responsividade: Em mobile, prefira tamanho sm ou md para economizar espaço vertical.
♿
Acessibilidade: Sempre forneça feedback textual adicional além do indicador visual de progresso.
🔄
Atualização: Atualize o valor do progresso de forma suave com intervalos de no mínimo 100ms para melhor performance.
