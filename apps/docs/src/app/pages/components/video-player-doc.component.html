Inputs

Propriedade Tipo Padrão Descrição
sources VideoSource[] [] Array de fontes de vídeo
subtitles Subtitle[] [] Array de legendas disponíveis
config VideoPlayerConfig {{'{}'}} Configurações do player
width string '100%' Largura do player
height string 'auto' Altura do player

Outputs

Evento Tipo Descrição
play void Emitido quando o vídeo começa a tocar
pause void Emitido quando o vídeo é pausado
ended void Emitido quando o vídeo termina
timeUpdate number Emitido quando o tempo atual muda
volumeChange number Emitido quando o volume muda
