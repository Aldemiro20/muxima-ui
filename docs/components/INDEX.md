## 📦 Instalação por Componente

### Pacote Completo (Recomendado)

```bash
npm install @muxima-ui/core
```

### Componentes Individuais

```bash
# Alert
npm install @muxima-ui/alert

# Progress
npm install @muxima/progress

# Avatar
npm install @muxima/avatar

# E assim por diante...
```
